SAMPLE WEBSITE — Libreng Hosting Guide
=======================================

Ano ito?
- Simpleng portfolio website (HTML + CSS lang, walang build step).
- Gamitin ito sa Chapter 3 ng guide para ma-publish ang una mong website.

Mga files:
- index.html   → ang homepage (dapat nasa pinakataas ng folder, hindi naka-subfolder)
- styles.css   → ang design ng page
- .nojekyll    → nagsasabi sa GitHub Pages na huwag nang i-build; i-serve lang ang files

Paano gamitin (buong steps nasa guide):
1. I-upload ang dalawang file (index.html + styles.css) sa GitHub repository mo.
2. Buksan ang Settings → Pages → Deploy from a branch → main + / (root) → Save.
3. Hintayin ng 1-2 minuto, tapos buksan ang https://USERNAME.github.io/REPO/

Gusto mong palitan ang pangalan at kulay?
- Buksan ang index.html sa Notepad (o kahit anong text editor) at palitan ang text.
- Buksan ang styles.css at palitan ang --blue at --purple values.

Walang kailangang i-install. Good luck sa una mong deploy!
